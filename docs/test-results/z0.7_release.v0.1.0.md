## TL;DR

- **The consumer contract passes:** `ozr.contract.check_release(manifest)` returns `[]` for `releases/v0.1.0/manifest.json`.
- **The release gate fails with 137 errors** and the command exits 1: 134 district coverage errors and 3 statute-quote errors. Nothing was loosened, and no placeholder cells were added. The Z0 report sets out the cause and the options.
- Two builds, before and after the statute sources were fetched, gave byte-identical `cells.json` and `cells.parquet` (same sha256). Only `sources.json` changed, because it now lists the 8 statute sources.
