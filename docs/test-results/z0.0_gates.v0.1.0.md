# Z0.0 gates: fail-first evidence (v0.1.0)

**Date:** 2026-10-09 · **Gates:** contamination check (`ozr.contamination`), private-term fingerprint check (`ozr.fingerprints`)

## Method

The gate logic was replaced by stubs that accept everything, and the suite was run; then the real code was restored and the suite re-run. Stubs:
- `host_banned` returns `False` (no host is ever banned);
- the https requirement in `_url_errors` is skipped;
- `find_hits` returns an empty set (no fingerprint ever hits).
